# Case-study image masters

Original BODi screenshot and DreamWorks artwork are preserved here, outside the
served site. Active inline images use WebP variants at 320, 640, and 1080 pixels
wide, sized proportionally with Pillow LANCZOS and encoded at quality 85/method 6.
The BODi link opens a separate full-resolution 1922 × 935 WebP, quality 92/method 6.
Both portfolio entry pages use width-based srcset and sizes; the DreamWorks
film switcher updates srcset along with src. Do not deploy this reference folder.
