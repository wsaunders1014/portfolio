# Original component reference snapshots

Exact local snapshots preserved during the portfolio demo work. The sibling repositories are untouched. These files stay outside src and are not built or deployed. Only the explicitly selected excerpts in src/lab/source/original-snippets.ts are displayed publicly, with attribution and original/adapted labels. SHA-256 digests are recorded in manifest.json.

The full `.tsx` snapshots are ignored by Git. The optional provenance test runs
when they are available locally and skips on a fresh clone without them.
